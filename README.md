# DayRise
A Student Productivity assistant built using Python and streamlit.

🌅 DayRise – Small Steps, Big Dreams

A student productivity assistant built with Python and Streamlit to help students organise tasks, track progress and maintain a balanced daily routine.

✨ Features

- 📋 Task Management: Add, delete, complete and prioritise tasks.
- 📊 Progress Dashboard: Track daily productivity and completed tasks.
- 🔥 Daily Streak: Monitor consecutive days of task completion.
- ⏱️ Focus Timer: 25-minute focus sessions and 5-minute breaks.
- 📓 Personal Notes: Save daily thoughts and reminders.
- 🌷 Mood Tracker: Record moods and visualise mood trends.
- 💡 Smart Suggestions: Get activity suggestions based on energy, available time and goals.
- 💾 Data Storage: Save application data using JSON files.

🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- HTML
- CSS
- JavaScript
- JSON

🚀 Getting Started

1. Clone the repository

git clone YOUR_REPOSITORY_URL

2. Open the project folder

cd DayRise

3. Install dependencies

pip install -r requirements.txt

4. Run the application

streamlit run app.py

DayRise aims to make student productivity easier through task organisation, focused work sessions, progress tracking and personal well-being features.
